22      * Rewrites the encoder parameter to fit the lens fields - auto renaming without config for datasets.
23      *
24      * It works by assuming I_AM_A_FIELD in java / scala is represented by the bean field iAmAField.  This can be extended by the unificationExtension param.
25      *
26      * If the field name is radically different you can use the unificationExtension to specifically look for the field (without underscores)
27      *
28      * Assumptions: no duplicate fields exist after removing symbols e.g. there shouldn't be both I_AM_A_FIELD and IAMAFIELD or IAM_A_FIEL_D for that matter.
29 
30      * @param readViaBean - when true the BeanEncoder will read from a normal bean encoder but output as BeanEncoder - use this for map transformations
31      * @param unificationExtension provide an optional extension to handle odd field names
32      * @param unificationMapExtension override and extend the Map used for field aliasing
33      * @return
34      */
